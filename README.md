# Portfolio Website

A simple, responsive personal portfolio website built with HTML, CSS, and JavaScript.

## Run locally

From this folder, run:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Customize

Edit the content in `index.html` and update the colors and styling in `styles.css`.

## Files

- `index.html` — page structure and content
- `styles.css` — styling and layout
- `script.js` — mobile menu behavior and year update
